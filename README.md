# SPINN-PTF
This repository provides the BETA version of the SPINN-PTF code described in 'Soil Physics-Informed Neural Networks to Estimate Bimodal Soil Hydraulic Properties'.
The code is completed by python3 and required packages including: torch (https://pytorch.org/index.html), numpy, pandas.
Note: The user needs to update 'texture.csv' with the soil information and then runs 'SPINN_PTF.py' to get the soil hydraulic parameters (created in three csv files).
